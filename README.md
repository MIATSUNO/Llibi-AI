# Llibi AI

A Llibi é uma assistente digital criada por Miatsuno para ajudar em tarefas do dia a dia. O projeto oferece opções de configuração, ícone personalizável, avatar de pet e mensagens rápidas, conforme a configuração disponível.

- [Acessar o site da Llibi](https://llibi.neocities.org/)

## Aplicativo Android

O arquivo `com.llibi.app.companion.apk` está disponível neste repositório como build para teste. As informações sobre instalação, compatibilidade e versão devem ser confirmadas no próprio aparelho e no site do projeto.
